# 🏥 MyKare AI Clone

A modern AI-powered healthcare website inspired by MyKare AI. This project demonstrates a responsive and visually appealing healthcare platform built using React, Vite, and Express. It focuses on delivering a clean user interface, smooth animations, and an intuitive user experience for healthcare services.

🔗 https://mykare-ai-clone.vercel.app/

## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/tanishasoni07/mykare-ai-clone.git
```

### Navigate to the Project

```bash
cd mykare-ai-clone
```

### Install Dependencies

```bash
npm install
```

### Start Development Server

```bash
npm run dev
```

### Build for Production

```bash
npm run build
```
